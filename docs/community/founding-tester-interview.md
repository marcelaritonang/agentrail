## Interview prompts

1. What task category did you try to inspect with AgentRail?
2. Where did your current AI workflow lose context or produce a context miss?
3. Which sources were useful sources for recovering the right context?
4. Which sources were irrelevant sources that should have been excluded?
5. What was your latency perception during install, local run, or inspection?
6. What privacy concern would stop you from using AgentRail on real work?
7. If you would uninstall it, what is the uninstall reason?
8. May AgentRail use one anonymized quote from this feedback?

# Langkah 0 — Pastikan Indonesia Eligible untuk AWS Activate (SEBELUM keluar uang)

> Tujuan: dapat jawaban RESMI dari AWS apakah startup berbasis Indonesia bisa
> menerima AWS Activate Founders credits. Gratis. Lakukan ini SEBELUM beli domain.

---

## Kenapa langkah ini dulu?
Halaman resmi AWS TIDAK menyebut syarat negara. Jadi kita tidak tahu pasti apakah
Indonesia diterima. Daripada tebak-tebakan lalu rugi beli domain, tanya langsung.
Kalau jawabannya "ya" → lanjut beli domain. Kalau "tidak" → hemat uang, pindah ke
Kiro Free.

---

## Cara 1 — Form kontak AWS Startups (paling cepat)
1. Buka: **aws.amazon.com/startups** → cari tombol "Contact us" / "Contact Sales".
2. Atau buka **aws.amazon.com/contact-us/** → pilih kategori "Startups / Activate".
3. Tempel pesan di bawah (bagian "PESAN SIAP-KIRIM").

## Cara 2 — AWS Support Center (kalau sudah punya akun AWS)
1. Login ke console.aws.amazon.com → Support → Create case → Account & billing.
2. Tempel pesan yang sama.

## Cara 3 — Email Activate (jika tersedia)
- Beberapa region pakai: **aws-activate@amazon.com** (cek balasan otomatis untuk
  arahan resmi). Kirim pesan yang sama.

---

## PESAN SIAP-KIRIM (Bahasa Inggris — copy paste)

```
Subject: AWS Activate Founders eligibility for an Indonesia-based startup

Hello AWS Startups team,

I am a founder of an early-stage startup legally based in Indonesia
(registered as a PT / Perseroan Terbatas). We are pre-Series B, founded
within the last few years, and we are building an AI product.

Before I set up everything, I would like an official confirmation:

1. Is a startup legally based in Indonesia eligible to apply for and receive
   AWS Activate Founders credits?
2. Are there any country or region restrictions I should be aware of for
   Indonesia specifically?
3. Do I need to be affiliated with a VC, accelerator, or incubator to receive
   the Founders tier, or can a self-funded (bootstrapped) startup apply?
4. Can AWS Activate credits be applied toward Kiro (kiro.dev) usage?

Thank you very much for your help.

Best regards,
[Nama kamu]
[Nama startup]
```

---

## Yang harus kamu isi sebelum kirim
- `[Nama kamu]` → nama lengkapmu
- `[Nama startup]` → nama startup/PT kamu (kalau belum ada, tulis rencana namanya)

## Setelah dapat jawaban
- **Kalau "Indonesia eligible + bootstrap boleh"** → 🎉 lanjut ke `STATUS.md` B2
  (beli domain). Jalur Activate hidup.
- **Kalau "harus VC / harus negara tertentu"** → jalur Activate juga tertutup untuk
  bootstrap Indonesia. Pindah ke **Kiro Free** ($0, pasti jalan) sambil membangun
  startup sampai suatu hari dapat VC.

---

## Catatan
- Jawaban AWS bisa perlu 1–3 hari kerja. Sabar.
- Simpan email balasannya sebagai bukti eligibility saat apply nanti.
- JANGAN beli domain / entitas sebelum jawaban ini keluar.
